# PlayerTrace

一个轻量级的 Nukkit-MOT 服务器插件，提供死亡坐标记录与玩家挂机检测功能。

## 功能特性

- 玩家死亡时自动记录并提示精确坐标。
- 实时监控玩家坐标，长时间未操作自动判定为挂机状态。
- 支持查询自己或指定玩家的挂机时长。

## 指令与权限

| **指令**          | **说明**                     | **权限** |
| ----------------- | ---------------------------- | -------- |
| `/back`           | 传送回上一次死亡的坐标       | 默认可用 |
| `/afktime [玩家]` | 查询自己或指定玩家的挂机时长 | 管理员   |

## 安装与使用

1. 将编译好的 `.jar` 文件放入服务器的 `plugins` 目录中。
2. 启动或重启服务器。

## 开发环境

- 服务端核心：Nukkit-MOT
- 开发语言：Java
